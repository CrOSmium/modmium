## Arch Linux:
```bash
yay -S --needed curl wget jq 7zip util-linux coreutils vboot-utils
yay -S inkscape # Optional, only required for custom bootsplash
```

## Debian (requires sid repo)
```bash
sudo apt update
sudo apt install -y curl wget p7zip-full util-linux coreutils sed vboot-utils
sudo apt install -y inkscape # Optional, only required for custom bootsplash
```
